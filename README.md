## Что есть на сайте

- история группы, участники, альбомы и интересные факты;
- кнопка смены темы (светлая / тёмная), выбор запоминается;
- кнопки "Подробнее" у участников показывают и скрывают описание;
- кнопки "Предыдущий" и "Следующий" листают альбомы по кругу;
- кнопка "Показать факты" открывает скрытый блок и прокручивает к нему;
- кнопка "Ещё факт" показывает следующий факт.

## Файлы

- `index.html` - разметка
- `styles.css` - стили
- `app.js` - кнопки и данные об альбомах и фактах
- `images/` - фото группы и обложки альбомов

## Как открыть

Открыть `index.html` в браузере.
